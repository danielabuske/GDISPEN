**Description**
This directory contains the datasets, figures, and supporting files used in the hydrological analyses presented in the article. The files are organized according to their purpose in the study.

 Directory structure

 **Hydrographs**
Contains hydrographs and streamflow figures used to evaluate and illustrate the hydrological simulation results, including calibration and validation periods and mean annual streamflow.

 **Maps**
Contains the spatial figures used to characterize the study area, including:

- Digital Elevation Model (DEM);
- Land use and land cover;
- Monitoring stations;
- Soil classes;
- Watershed location.

 **Observed_Precipitation_vs_IMERG**
Contains figures comparing gauge-observed precipitation with IMERG satellite precipitation for the monitoring stations used in the study. These files support the evaluation of the agreement between ground-based and satellite precipitation estimates.

 **Precipitation/Daily_data**
Contains the daily precipitation datasets used in the study:

- `IMERG - Precipitation.xlsx`: daily precipitation data derived from IMERG;
- `Station data.xlsx`: daily precipitation data from ground-based monitoring stations.

These datasets were used for the comparison between observed and satellite precipitation and as precipitation inputs for the hydrological analyses.

 **StreamFlow**
Contains the streamflow datasets used in the hydrological evaluation. The files are organized according to temporal resolution and simulation period, including:

- daily streamflow for the calibration period;
- daily streamflow for the validation period;
- complete daily streamflow series;
- monthly streamflow for the calibration period;
- monthly streamflow for the validation period;
- complete monthly streamflow series;
- annual streamflow data.

These datasets support the calibration, validation, and evaluation of the hydrological model at different temporal scales.
